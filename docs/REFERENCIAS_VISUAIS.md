# Referências Visuais — ARL Informática

As imagens devem ser anexadas ao Codex Cloud e/ou posteriormente adicionadas ao repositório em `docs/referencias/`.

Mapeamento oficial:

1. `01-painel-menu` — Painel inicial, menu lateral, cards, tabela principal, filtros, paginação e identidade visual Web/PC.
2. `02-clientes` — Cadastro/listagem de clientes e referência de responsividade.
3. `03-nova-os` — Tela Nova OS / abertura de chamado.
4. `04-status` — Dropdown rápido de alteração de status.
5. `05-pdf-final-a4` — Pré-visualização e PDF A4 do fechamento da OS.
6. `06-pos-venda` — Inspiração visual do Pós-Venda; funcionalmente seguir o modelo simplificado do Projeto Mestre.
7. `TIMBRADO.png` — Referência visual oficial para Orçamentos e Laudos Técnicos.
8. `logo-arl` — Logomarca da empresa, quando fornecida separadamente.

## Regras de fidelidade

- Desktop deve seguir as referências com máxima fidelidade razoável.
- Não substituir por template genérico.
- Antes de finalizar tela, abrir aplicação, capturar screenshot, comparar e ajustar.
- Mobile/Tablet não copia a tabela desktop; segue experiência própria descrita em `docs/PROJETO_MESTRE.md`.
- Dados antigos impressos na imagem TIMBRADO não devem ser hardcoded; usar os dados configuráveis da empresa.
